# PortafolioWeb_IsaacQ 🚀

## Portafolio Web Profesional con Diseño UX/UI Moderno

Este es un portafolio web profesional diseñado con las mejores prácticas de UX/UI, enfocado en la experiencia del usuario, diseño responsivo y accesibilidad.

## ✨ Características Principales

### Diseño y Experiencia de Usuario (UX)
- **Diseño Centrado en el Usuario**: Navegación intuitiva y clara jerarquía visual
- **Responsive Design**: Adaptable a todos los dispositivos (móvil, tablet, desktop)
- **Accesibilidad**: Implementación de etiquetas ARIA y HTML semántico
- **Animaciones Suaves**: Transiciones fluidas que mejoran la experiencia sin distraer
- **Carga Optimizada**: Lazy loading y optimización de recursos para mejor rendimiento

### Interfaz de Usuario (UI)
- **Diseño Moderno**: Paleta de colores vibrante con gradientes y efectos visuales
- **Tipografía Legible**: Fuente Poppins con jerarquías claras
- **Sistema de Grid**: Diseño basado en CSS Grid y Flexbox
- **Microinteracciones**: Efectos hover, transiciones y feedback visual
- **Modo Oscuro**: Esquema de colores optimizado para reducir fatiga visual

### Secciones Incluidas
1. **Hero/Inicio**: Presentación impactante con CTA claro
2. **Sobre Mí**: Información personal y estadísticas destacadas
3. **Habilidades**: Categorización visual de competencias técnicas
4. **Proyectos**: Showcase de trabajos con etiquetas y enlaces
5. **Experiencia**: Línea de tiempo profesional
6. **Contacto**: Formulario funcional y múltiples métodos de contacto

## 🎨 Tecnologías Utilizadas

- **HTML5**: Estructura semántica y accesible
- **CSS3**: Estilos modernos con variables CSS, Grid, Flexbox
- **JavaScript (Vanilla)**: Interactividad sin dependencias
- **Font Awesome**: Iconografía profesional
- **Google Fonts**: Tipografía Poppins

## 🚀 Características Técnicas

### Performance
- Optimización de imágenes y recursos
- Lazy loading para elementos multimedia
- Minimización de reflow y repaint
- Uso eficiente de CSS transforms para animaciones

### Accesibilidad (a11y)
- HTML semántico con elementos apropiados
- Etiquetas ARIA para mejor navegación con lectores de pantalla
- Contraste de colores siguiendo WCAG 2.1
- Navegación completa por teclado
- Focus states visibles y claros

### SEO
- Meta tags optimizados
- Estructura de encabezados jerárquica
- URLs amigables (smooth scroll anchors)
- Descripción y keywords relevantes

### UX Features
- Scroll suave entre secciones
- Indicador visual de sección activa en navegación
- Animaciones on-scroll para revelar contenido
- Formulario con validación en tiempo real
- Sistema de notificaciones para feedback
- Menú hamburguesa responsive en móvil

## 📱 Responsive Design

El sitio se adapta perfectamente a:
- **Desktop**: 1200px+
- **Tablet**: 768px - 1199px
- **Mobile**: 320px - 767px

### Breakpoints Principales
```css
@media (max-width: 968px)  /* Tablets y móviles grandes */
@media (max-width: 768px)  /* Móviles */
@media (max-width: 480px)  /* Móviles pequeños */
```

## 🛠️ Instalación y Uso

### Uso Local
1. Clona el repositorio:
   ```bash
   git clone https://github.com/isaacquinapallo/PortafolioWeb_IsaacQ.git
   ```

2. Abre `index.html` en tu navegador:
   ```bash
   cd PortafolioWeb_IsaacQ
   open index.html  # Mac
   start index.html # Windows
   xdg-open index.html # Linux
   ```

### Despliegue
El sitio es completamente estático y puede desplegarse en:
- GitHub Pages
- Netlify
- Vercel
- Cualquier servidor web estático

## 📝 Personalización

### Colores
Modifica las variables CSS en `styles.css`:
```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #ec4899;
    /* ... más variables */
}
```

### Contenido
Edita el contenido directamente en `index.html`:
- Información personal en secciones
- Links de redes sociales
- Proyectos y habilidades
- Información de experiencia

### Funcionalidad
Personaliza el comportamiento en `script.js`:
- Velocidad de animaciones
- Comportamiento del formulario
- Efectos de scroll
